# 10-day build / commit plan

Each day adds one coherent piece of the final project. After each day: run the listed check, then commit.

| Day | Content added | Check before committing | Suggested commit message |
|---|---|---|---|
| 1 | Repo skeleton, `.gitignore`, `requirements.txt`, `environment.yml`, dataset download script, `rb/data.py`, data tests, commit-log exporter | `python scripts/prepare_data.py` then `python tests/test_data.py` | `Day 1: project skeleton, environment files and CIFAR-10 data pipeline` |
| 2 | `rb/models.py` (CNN, ResNet-18, EfficientNet-B0), basic training loop, **checkpoint saving**, `scripts/train_baseline.py` | train CNN 1 epoch | `Day 2: models, standard training loop and checkpointing` |
| 3 | `rb/corrupt.py` part 1: seen corruptions (Gaussian noise, salt-and-pepper, Gaussian blur) + severity table | corruption unit tests | `Day 3: seen corruption suite (noise, salt&pepper, blur)` |
| 4 | Unseen corruptions (brightness, contrast, pixelate, motion blur, fog, speckle) + FGSM / PGD-10 | attack tests (eps bound, range) | `Day 4: unseen corruptions and adversarial attacks` |
| 5 | `rb/evaluate.py` (accuracy, ECE, NLL, per-class), `run_experiment.py` baseline evaluation | baseline CNN full evaluation CSV | `Day 5: evaluation pipeline and baseline robustness results` |
| 6 | Training variants: fixed corruption-aware, FGSM adversarial training, fixed mix (control) | 1-epoch run of each variant | `Day 6: corruption-aware and adversarial training variants` |
| 7 | Adaptive scheduler (`adaptive`, `adaptive_norm`) | adaptive run logs probabilities | `Day 7: adaptive corruption-aware training scheduler` |
| 8 | Uncertainty: temperature scaling, abstention threshold, risk-coverage, AUROC | abstention metrics in CSV | `Day 8: uncertainty-aware prediction and abstention` |
| 9 | `report.py`, `run_all.sh`, full results/figures, trained checkpoints (or HF link) | `bash run_all.sh` completes | `Day 9: full experiments, figures and checkpoints` |
| 10 | CVPR LaTeX report, reproducibility declaration, final README, commit log | `python scripts/export_commit_log.py` | `Day 10: CVPR report, reproducibility declaration and final README` |

## Assignment checklist
- [ ] GitHub repository link  (create empty repo on GitHub, then `git remote add origin <url>` and `git push -u origin main`)
- [ ] CVPR-format 8-page report  (`report/`, Day 10)
- [ ] Commits, hashes, timestamps  (`docs/COMMIT_LOG.md`, generated by `scripts/export_commit_log.py`)
- [ ] Environment file  (`requirements.txt`, `environment.yml`)  — Day 1
- [ ] Reproducibility artifacts + declaration statement  — Day 10 (`REPRODUCIBILITY.md`)
- [ ] Instructions to reproduce  — README, grows daily
- [ ] Checkpoints (or Hugging Face link + size justification)  — Day 2 / Day 9
- [ ] No dataset files in the repo  — enforced by `.gitignore`, rebuilt via `scripts/prepare_data.py`
- [ ] Proper directory structure  — see README
